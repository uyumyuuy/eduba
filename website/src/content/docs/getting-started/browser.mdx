ブラウザ版は、PDF の読み込み、OCR、校正、書き出しを端末内で処理します。PDF や校正内容をサーバーに送信しません。初回の読み込みや OCR の開始時には、アプリと学習済みモデルをこのサイトから取得します。

## 使い始める

1. ブラウザ版を開き、「PDF を読み込む」から端末内の PDF を選択します。
2. 取り込む範囲や画像の向きを確認して、プロジェクトを作成します。
3. OCR を実行し、原画像と見比べながら認識結果を校正します。
4. 「プロジェクトを保存」で `.eduba` ファイルを端末に保存します。

既存の `.eduba` ファイルも開けます。デスクトップ版で指定したモデルのファイルパスはブラウザで使えないため、既定モデルに切り替わります。独自の `.traineddata` を使う場合は、設定画面から選び直してください。

## 作業の保存と復元

編集中の内容はブラウザ内に自動保存され、同じサイトを開くと作業を再開できます。「作業中のプロジェクト」から、以前の作業コピーを開くこともできます。

この自動保存と、端末内の `.eduba` ファイルへの保存は別です。作業を終えるときや別の端末へ移すときは、「プロジェクトを保存」を使ってください。ブラウザがファイルへの直接保存に対応している場合は保存先を選べます。それ以外ではファイルがダウンロードされます。

不要な作業コピーは「作業中のプロジェクト」の一覧から「削除」を選び、確認ダイアログで確定すると削除できます。そのコピーの PDF・OCR 結果・校正履歴がブラウザから消えます。開いているプロジェクトを削除すると、そのプロジェクトは閉じます。端末に保存済みの `.eduba` ファイルや、他の作業コピー・設定・独自モデルは残ります。必要な内容は先にファイルへ保存してください。

:::caution[バックアップを保存してください]
ブラウザ内の作業コピーは、サイトデータの削除などで失われます。別のブラウザや、ローカル開発用 URL からは参照できません。必要なプロジェクトは `.eduba` ファイルに保存してください。
:::

## 利用上の制限

- 同じサイトでプロジェクトを扱うタブは1つにしてください。
- 独自モデルはブラウザ内に保存されます。`.eduba` には含まれないため、別の端末ではモデルも選び直してください。
- 大きな PDF では、ブラウザのメモリと保存容量の制限を受けます。モバイルや1,000ページ規模の性能は未確認です。
- オフラインでの起動にはまだ対応していません。
