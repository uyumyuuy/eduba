---
title: 最初のプロジェクト
description: PDF を取り込み、OCR して校正するまで
---

1. Eduba を起動し、「PDF を読み込む」を選びます。
2. 取り込みプレビューでページ画像や対象ページを確認します。設定を確定すると `.eduba` プロジェクトが作成されます。
3. 初期設定の英語向けモデルを使う場合は、そのまま [OCR](/guides/ocr/)を実行します。別の `.traineddata` を使う場合は、OCR 前に設定画面から選択します。
4. 左右のペインで原画像と認識テキストを見比べ、[校正](/guides/proofreading/)します。
5. 段組みなどで読み順の調整が必要なときは、[OCR 領域と読み順](/guides/regions/)を確認します。
6. 校正した結果を[書き出し](/guides/exporting/)ます。

プロジェクトは単一の `.eduba` ファイルに保存されます。変更は自動保存され、次回起動時に前回のプロジェクトを開き直せます。

別のプロジェクトに戻るときは、[作業中のプロジェクト](/guides/working-projects/)から選択できます。デスクトップ版では過去に作成・開いたファイル、ブラウザ版ではブラウザ内の作業コピーを表示します。
