# Eduba 1.0.0

スキャンした英語の本・論文の OCR と校正を行うデスクトップアプリ、Eduba の Windows 版を公開します。

## 主な機能

- PDF の取り込み、画像抽出、回転・見開き分割
- 同梱の Tesseract と Assyrian-OCR 基準モデルによる端末内での OCR
- 行単位の校正、LSTM の文字候補とモデル専用校正候補表による候補表示
- OCR 領域・図表領域・読み順の編集、Undo/Redo
- 校正モードと閲覧モードの切り替え
- `.eduba` プロジェクトの保存・再オープン、作業中のプロジェクト一覧からの再開
- TXT、hOCR、HTML、SVG への出力
- 日本語、英語、簡体字中国語、繁体字中国語の UI

## インストール

対象は Windows x64 です。

- 通常は **Eduba_1.0.0_x64-setup.exe** を使用してください。
- MSI が必要な環境では **Eduba_1.0.0_x64_en-US.msi** を使用してください。

OCR エンジンとモデルは同梱されており、別途 Tesseract をインストールする必要はありません。PDF の処理と OCR は端末内で行います。

インストーラーは署名なしのため、Windows の警告が表示される場合があります。WebView2 が未導入の場合、インストール時に取得のためのネットワーク接続が必要です。macOS・Linux 用の配布物は今回のリリースには含みません。

## 同梱モデルと配布情報

- OCR エンジン：Tesseract 5.5.3
- 基準モデル：`eng_assyriology_charset_expanded_250x_20261023`（Apache-2.0）
- 上記モデル専用の校正候補表を同梱

モデル単体は [OCR モデル専用 Release](https://github.com/uyumyuuy/eduba/releases/tag/ocr-model-20261023-charset-expanded-250x-candidates-20261027) から取得できます。
`BUILDINFO.json` にソースコミットと同梱モデルの識別情報、`SHA256SUMS` に配布ファイルの SHA-256 を記録しています。ライセンス、通知文、元の provenance も添付しています。

使い方は [ヘルプドキュメント](https://eduba.kurnugia.com/) を参照してください。[ブラウザ版](https://eduba.kurnugia.com/app/) も利用できます。
